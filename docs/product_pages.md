# 产品页面规划

本阶段目标是搭建产品级网站外壳，不优化因子研报工作流内部细节。

## 页面

### `/login`

账号密码登录页，提供 GitHub 登录入口。

### `/register`

账号注册页。注册成功后自动登录并进入 dashboard。

### `/dashboard`

登录后的研究首页：

- 展示历史研究数量
- 展示本地持久化状态
- 展示最近研究列表
- 提供新建研究入口

### `/research/new`

新建研究页：

- 输入研究标题
- 输入投资想法
- 提交后调用当前 `run_demo_workflow()`
- 保存研究项目、运行记录和 trace

### `/research/:id`

研究详情页：

- 展示标题、投资想法和状态
- 展示指标摘要
- 展示完整 trace JSON
- 展示研究报告 Markdown

### `/settings`

账号设置页：

- 用户名
- 邮箱
- 当前支持的认证方式
